Clavier et souris, ou écran tactile. Le moteur 3D se charge au lancement.
Ouvrir dans un nouvel onglet

Jeu en 3D : ZQSD, WASD ou flèches pour bouger (touches et qualité graphique réglables dans le menu « Réglages »), souris pour regarder, clic pour attaquer/tirer, E pour interagir (boutique, casiers, ventilations), R pour recharger, L pour la lampe torche, Espace pour sauter, I pour l’inventaire, G pour siffler (dès l’étage 2). Sur tablette ou téléphone : pavé à gauche, glisser pour regarder, boutons d’action à droite.

Glossaire du petit hacker

CTF (Capture The Flag)

Un jeu de cybersécurité où l’on résout des épreuves pour trouver des « drapeaux » (des chaînes secrètes). C’est la meilleure façon de s’entraîner légalement.

Injection SQL

Une faille où le texte saisi par l’utilisateur est collé dans une requête de base de données et en change le sens. Parade : les requêtes préparées.

XSS (Cross-Site Scripting)

Une faille où une page affiche du contenu non filtré qui peut exécuter du code dans le navigateur d’un autre visiteur. Parade : échapper tout ce qui est affiché et utiliser une politique CSP.

Base64 : chiffrement ou pas ?

Pas du tout. C’est un simple encodage réversible par tout le monde. Il sert à transporter des données, pas à les protéger.

Empreinte (hash)

Une signature à sens unique d’un texte. Ce site vérifie tes drapeaux avec des empreintes : il n’a pas besoin de connaître la réponse en clair pour dire si tu as juste.

Entropie d’un mot de passe

Une mesure (en bits) du nombre d’essais qu’il faudrait pour le deviner. Chaque bit double le travail de l’attaquant. Un mot courant ou une suite de touches vaut très peu, même avec un chiffre à la fin.

Phishing (hameçonnage)

Un faux message ou faux site qui imite une marque pour te voler tes identifiants. Signes classiques : adresse bizarre, urgence, fautes, lien qui ne mène pas au vrai domaine.

k-anonymat (Have I Been Pwned)

Pour vérifier un mot de passe sans le révéler, on n’envoie que les 5 premiers caractères de son empreinte SHA-1. Le service renvoie toutes les correspondances et c’est ton navigateur qui compare.

Confiance côté client

Tout ce qui s’exécute dans ton navigateur peut être modifié par toi. Les vraies vérifications (droits, prix, rôles) doivent se faire sur le serveur.
