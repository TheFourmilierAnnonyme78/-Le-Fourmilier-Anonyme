# -Le-Fourmilier-Anonyme
Un site parodique pour apprendre la cybersécurité en s’amusant, accompagné de Nuit blanche, un jeu d’horreur en 3D jouable directement dans le navigateur.  Tout tient en quelques fichiers HTML : pas d’installation, pas de serveur, pas de base de données. Tout est simulé et sauvegardé dans ton navigateur, et rien n’est envoyé sur Internet.
